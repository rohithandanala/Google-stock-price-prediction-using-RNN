============
Installation
============


Stable release
--------------

To install Time Series Forecasting of Stock Prices Using Deep Learning, run this command in your terminal:

.. code-block:: console

    $ pip install time_series_forecasting_of_stock_prices_using_deep_learning

This is the preferred method to install Time Series Forecasting of Stock Prices Using Deep Learning, as it will always install the most recent stable release.

If you don't have `pip`_ installed, this `Python installation guide`_ can guide
you through the process.

.. _pip: https://pip.pypa.io
.. _Python installation guide: http://docs.python-guide.org/en/latest/starting/installation/


From sources
------------

The sources for Time Series Forecasting of Stock Prices Using Deep Learning can be downloaded from the `Github repo`_.

You can either clone the public repository:

.. code-block:: console

    $ git clone git://github.com/RohithAndanala/time_series_forecasting_of_stock_prices_using_deep_learning

Or download the `tarball`_:

.. code-block:: console

    $ curl -OJL https://github.com/RohithAndanala/time_series_forecasting_of_stock_prices_using_deep_learning/tarball/master

Once you have a copy of the source, you can install it with:

.. code-block:: console

    $ python setup.py install


.. _Github repo: https://github.com/RohithAndanala/time_series_forecasting_of_stock_prices_using_deep_learning
